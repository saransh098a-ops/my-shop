⚙️ Settings

💳 Razorpay Payment Settings

To enable real payments, add your Razorpay keys

Step 1: Go to razorpay.com and sign up
Step 2: Settings → API Keys → Generate Test Key
Step 3: Open js/app.js on GitHub
Step 4: Find: rzp_test_YourTestKeyHere
Step 5: Replace with your actual Key ID
Step 6: Save and deploy

🛍️ How to Add Products

Step 1: Go to your GitHub repository
Step 2: Open js/app.js file
Step 3: Click pencil icon to edit
Step 4: Find the products array at top
Step 5: Add or edit product details
Step 6: Commit changes - website updates!

🎨 How to Change Colors

Step 1: Open css/style.css on GitHub
Step 2: Find --primary: #6C5CE7 at top
Step 3: Change color code to your color
Step 4: Commit changes

🔐 Change Admin Password

Step 1: Open admin.html on GitHub
Step 2: Find: if (pass === 'admin123')
Step 3: Replace admin123 with your password
Step 4: Commit changes
